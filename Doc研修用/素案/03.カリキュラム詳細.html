1. 研修の目的とゴールの説明

🕒 9:00 – 9:30

本日の研修のゴールを説明する。スライドにて概要を共有。

1-1. 背景（Why?）

🌐 昨今の市場変化

  • AIが単なるチャットからエージェント型の開発支援ツールへ進化
  • AI支援型開発の事例が急速に増加（GitHub Copilot / Cline / Cursor 等の台頭）

💬 エンドユーザー・顧客からの声

  • AIを活用して生産性・品質を向上させたい
  • AIを活用してよりスピーディ（短い）な開発サイクルを実現したい
  • AIを自社サービスに組み込み問題解決（収益構造・人手不足の対策）を図りたい
    • コールセンター無人化（SMBC事例）
    • SKI-AI面接官

🚀 SKIにて動いている案件

案件一覧資料を用いて説明 — 想定以上にAI関連案件が稼働していることを共有する。

1-2. 我々が守りたい立ち位置

✅ OK：顧客と伴走し、AI時代も顧客の課題解決にコミットする存在であり続けたい
⚠️ NG：顧客からの相談事に乗れない（「この問題はAIで解決できますね」の流れに乗れない）
⚠️ NG：顧客にAI標準化プロセスが提供されるまで無関心（「何をすればいいですか？」の悪い下請けスタンス）

近い将来（今年・来年）にAIを活用した開発が当たり前の世界が来ると予想される中で、顧客は業務・システム・設計・実作業を抑えている我々に対して相談が来ると予想される。

1-3. 本日のゴール

  • AI支援型開発時代のSE作業を体験し、AIを活用した開発のイメージを掴むこと。SEに戻る1日!
  • 参加者全員にVS Codeを使って全カリキュラムを消化してもらう
  • 明日顧客からAIを活用した開発の相談が来たときに、どのように対応すればいいかのイメージを持つこと

📋 本日の時間割り — 作成済みのカリキュラム詳細スライドにて説明する。

  • 画面遷移図に従ってブラウザで画面を確認
  • H2 Console でDBの中身を確認

6-2. テーマ一覧

例題

テーマ1：リコメンド（お勧め）フラグの機能追加

要件：

  • 画面に書籍の「お勧めフラグ」を追加する
  • 入力や編集時に指定することができるようにする
  • お勧めフラグがONの書籍は、書籍一覧画面でタイトルの横に「おすすめ」と表示される
👉 ここから下を各参加者に任せるセクションです。 要件に対し影響調査 → 設計書修正 → CD/UT → 動作確認の手順で進めます。

📝 各テーマ共通の進め方

  1. 影響調査 — docs/外部設計 より修正を要する設計書を列挙し内容を提示。HTML修正・img作成を含む 合否判定
  2. 設計書修正 — 内容が妥当であれば修正を実施 合否判定
  3. コーディング・テスト — CD_Executor.md / 単体テスト_Executor.md に従い実行。差分レポートを作成 合否判定
  4. 動作確認 — 手動で画面操作を行い検証

テーマ2：カテゴリーメンテナンス機能の追加

⭐⭐⭐ 難易度：3

要件：

  • 現状DBに固定設定されている「カテゴリー」のメンテナンス機能を追加
  • 遷移元は一覧画面からの「カテゴリー管理」ボタン
  • カテゴリー管理画面では新規登録・編集・削除が可能
  • 編集で修正できるのはカテゴリー名のみ
  • 既に書籍データがある場合は削除不可

テーマ3：出版社による検索機能の追加

⭐⭐ 難易度：2

要件：

  • 書籍の検索機能に「出版社による検索」を追加
  • 出版社はプルダウンで選択可能にする
  • 出版社はDBマスター管理ではなく、既存の書籍データより重複排除してプルダウンに表示

テーマ4：マルチユーザー対応

⭐⭐⭐⭐ 難易度：4

要件：

  • シングルユーザーから「一般ユーザー」「管理ユーザー」の2種類に拡張
  • 一般ユーザーは閲覧のみ、管理ユーザーは登録・編集・削除が可能
  • 社内利用限定のため認証機能は不要。メールアドレス・名前のみで管理
  • トップ画面を一覧画面からユーザー選択画面（新設）に変更
  • レビュー画面のユーザー名は選択画面で選んだユーザー名を引き継ぎ
  • 楽観ロックチェックを導入（ユーザー名＋更新日時で判定）

テーマ5：レビューの削除機能の追加

⭐⭐⭐ 難易度：3

要件：

  • 書籍詳細画面のレビュー一覧に「削除」ボタンを追加
  • 削除ボタン押下で確認メッセージを表示後、削除を実行
  • 削除完了後は書籍詳細画面に戻る
  • 自分のレビューデータのみが削除可能（制御が必要）

テーマ6：書籍一覧のCSVダウンロード機能の追加

⭐⭐ 難易度：2

要件：

  • 書籍一覧画面に「CSVダウンロード」ボタンを追加
  • 現在の検索条件・ソート順を引き継いだデータをCSV出力
  • 出力項目：書籍ID・タイトル・著者・出版社・カテゴリ・出版日・価格・平均評価・レビュー数
  • ファイル名：books_YYYYMMDD.csv
  • 文字コード：UTF-8（BOM付き）、Excelで開けること
