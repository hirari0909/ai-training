# 研修カリキュラム

## ワークショップカリキュラム
9:00スタート(休憩12:00-13:00)

### 前工程 (30min- 9:00-9:30)
- 研修の目的とゴールの説明(15min)

### 事前準備
- GitHubアカウントの作成
- ブラウザーからのGithubCodespacesの利用確認

### 1st step(15min- 9:30-9:45)
- 環境確認
- GitHub Codespacesの利用方法の説明

### 2nd step (15min- 9:45-10:00)
- Workspaceの内容の説明
- Server起動
- トップページの確認

### 3rd step (30min- 10:00-10:30)
- 設計書の説明
- プロンプトの説明

### 4th step (2h- 10:30-12:30)
- プロンプトの実行(CD)
- 結果の確認 / git commit
- 動作検証(Fromブラウザー/全画面・全ボタンの疎通確認)

### 5th step (1h- 12:30-13:30)
- プロンプトの実行(UTクラス作成・Junit/UT実施)
- 結果の確認

### 6th step (2h- 13:30-15:30)
- 機能追加プロンプトの作成・実行(設計)
- 設計の確認 / 合否判断
- CDプロンプトの作成・実行
- UTプロンプトの作成・実行
- 結果の確認 / git commit
  (進行に合わせて、機能追加プロンプトの作成・実行を繰り返す)

### 7th step (2h- 15:30-17:30)
- 所管・質疑応答
- 宿題説明

### 8th step (1h- 17:30-18:00)
- クロージング
