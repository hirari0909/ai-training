# 🤖 AIエージェントとは

> **本資料の目的**
> 「生成AIの基本特性」の次のステップとして、**AIエージェント**の概念と、システム開発現場での活用メリットを理解するための資料です。
> GitHub Copilot を例に、エージェントが「何をしてくれるのか」を具体的にイメージできるようになることを目指します。

---

## 📌 1. AIエージェントとは何か

### 1-1. 通常の生成AIとの違い

これまで学んだ生成AIは、「質問に答える」ことが基本でした。

```
【通常の生成AI】

  あなた ──→ プロンプト ──→ AI ──→ テキスト回答

  ・1問1答（質問 → 回答で終わり）
  ・回答を使って何かするのは"あなた"の役割
```

AIエージェントはここから一歩進み、**「判断して、自分で行動まで行う」** 存在です。

```
【AIエージェント】

  あなた ──→ 目標の指示 ──→ エージェント
                                  │
                          ┌───────┴────────┐
                          │  計画を立てる   │
                          └───────┬────────┘
                                  │ 繰り返し
                          ┌───────┴────────┐
                          │ ツールを呼び出す │ ← ファイル読み書き・コマンド実行・検索 etc.
                          └───────┬────────┘
                                  │
                          ┌───────┴────────┐
                          │ 結果を評価する  │
                          └───────┬────────┘
                                  │
                              ✅ 完了！
```

| 比較軸 | 通常の生成AI | AIエージェント |
|:---|:---|:---|
| **できること** | テキストを回答するだけ | 調べる・書く・実行する・確認する |
| **行動の主体** | あなたが次の一手を決める | エージェントが自律的に判断して進む |
| **完了までの手間** | 何度もプロンプトを投げる必要がある | 目標を伝えれば自動で進める |
| **ツール利用** | なし | ファイル操作・コマンド・Web検索など |

エージェントは以下の3要素が連携して動作します。

| 要素 | 役割 | 具体例（GitHub Copilot） |
|:---|:---|:---|
| **LLM（頭脳）** | 状況を判断し、次の行動を計画する | Claude / GPT-4o などのモデル |
| **ツール群（手足）** | 実際にファイルを読んだりコマンドを叩いたりする | ファイル編集・`mvn test` 実行・コード検索 |
| **コンテキスト（メモ帳）** | これまでの操作や読み込んだ内容を保持する | 開いているファイル・エラーログ・会話履歴 |

### 2-2. 具体的な違いを表で整理

| 作業内容 | エージェントなし | GitHub Copilot（エージェント） |
|:---|:---|:---|
| **ファイルを読む** | あなたがコピーしてAIに貼る | エージェントが自分で開いて読む |
| **コードを書く** | AIの回答をコピーしてエディタに貼る | エージェントが直接ファイルに書き込む |
| **ビルド・テスト実行** | あなたがターミナルで実行 | エージェントがコマンドを実行する |
| **エラー対応** | エラーログをコピーしてAIに聞く | エージェントがエラーを読んで自己修正 |
| **複数ファイルの横断** | 毎回コピーして渡す | エージェントが自律的に横断参照 |
| **あなたの負担** | 高い（常に橋渡し役が必要） | 低い（目標を渡して待つだけ） |

### 3-2. エージェントモードでできること・できないこと

| カテゴリ | できること ✅ | できないこと ⚠️ |
|:---|:---|:---|
| **ファイル操作** | 読む・書く・作成・削除 | 権限外のシステムファイル操作 |
| **コマンド実行** | `mvn test`・`git`・ターミナル全般 | 承認なしの危険なコマンド |
| **コード作成** | 複数ファイルにまたがる実装 | 要件の確認・ビジネス判断 |
| **エラー対応** | ログを読んで自己修正を試みる | 100%正しい修正の保証 |
| **設計判断** | 選択肢の提案 | アーキテクチャの最終決定 |

> [!WARNING]
> **エージェントの出力は必ずレビューすること！**
> エージェントは高速に作業しますが、「もっともらしいコード」を生成するだけで正しさを保証しません。
> 生成されたコードや設計書は、**必ず人間が内容を確認**してください。
