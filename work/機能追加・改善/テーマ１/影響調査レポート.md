# 影響調査レポート：書籍「お勧めフラグ」追加

## 1. 対象要件

```
・画面に書籍の「お勧めフラグ」を追加する
・入力や編集時に指定できるようにする
・お勧めフラグが ON の書籍は、書籍一覧画面でタイトルの横に「おすすめ」と表示されるようにする
```

## 2. 調査方針

- 調査範囲: `Docsシステム/外部設計` 配下の設計書のみ
- 本レポートは**影響調査のみ**であり、設計書本体・画面イメージ（HTML/img）はまだ修正していない
- 「お勧めフラグ」は books テーブルへの新規カラム追加として実現する前提で影響範囲を洗い出した
  - 物理名（案）: `is_recommended`（BOOLEAN/TINYINT(1)、NOT NULL、DEFAULT 0）
  - 論理名（案）: お勧めフラグ
  - ※最終的な物理名・型は詳細設計（`Docsシステム/詳細設計/ネーミングルール.md`）側で確定する想定のため、本レポートでは案として記載

## 4. 詳細な修正内容案

### 4.1 [03ER図.md](../../../Docsシステム/外部設計/03ER図.md)

`books` エンティティの mermaid 定義に1行追加。

```diff
     books {
         INT book_id PK "書籍ID"
         VARCHAR(100) title "タイトル"
         VARCHAR(50) author "著者"
         VARCHAR(50) publisher "出版社"
         DATE published_date "出版日"
         VARCHAR(13) isbn UK "ISBN"
         INT category_id FK "カテゴリID"
         INT price "価格"
         TEXT description "概要"
+        BOOLEAN is_recommended "お勧めフラグ"
         DATETIME created_at "作成日時"
         DATETIME updated_at "更新日時"
     }
```

---

### 4.2 [04TBL定義.md](../../../Docsシステム/外部設計/04TBL定義.md)

**books テーブル定義**にカラムを追加（`description` と `created_at` の間、#10 として追加し既存の created_at/updated_at の番号を +1）。

| # | 物理名 | 論理名 | 型 | 長さ | 精度 | NULL | デフォルト | 主キー | 外部キー | ユニーク | インデックス | 備考 |
|---|--------|--------|-----|------|------|------|-----------|--------|---------|---------|------------|------|
| 10 | is_recommended | お勧めフラグ | BOOLEAN(TINYINT(1)) | - | - | NOT NULL | FALSE(0) | - | - | - | - | ON:true(1) / OFF:false(0) |

- **CREATE TABLE SQL** の `books` 定義に `is_recommended BOOLEAN NOT NULL DEFAULT FALSE COMMENT 'お勧めフラグ'` を追加
- **サンプルデータ INSERT 文**の books に `is_recommended` の値（例: リーダブルコードのみ `TRUE`）を追加
- インデックス追加は不要（一覧画面での絞り込み・ソート要件がないため）
