# 設計書修正レポート：お勧めフラグ（recommended flag）機能

## 1. 概要

`work/機能追加・改善/テーマ１/影響調査レポート.md` の調査結果に基づき、「お勧めフラグ」機能の追加に必要な外部設計書を修正した。
**本対応ではコード（`training-bookshelf/src/main` 配下）は一切変更していない。設計書（`Docsシステム/外部設計/`配下のMD・HTML・画像）のみを修正した。**

追加する機能の要件（再掲）：
- 書籍登録画面（BK03）・書籍編集画面（BK06）で「お勧めフラグ」をON/OFF設定できる
- 書籍一覧画面（BK01）で、お勧めフラグがONの書籍のみ、タイトル横に「おすすめ」バッジを表示する

### 3.1 `03ER図.md`

**目的：** DB設計にお勧めフラグ列を反映し、以降のテーブル定義・画面設計の一次情報とするため。

**Before**
```
books {
    INT book_id PK "書籍ID"
    ...
    TEXT description "概要"
```

**After**
```

    INT book_id PK "書籍ID"

}
```

| ドキュメント | 理由 |
|-------------|------|

| BK05, BK08, BK09, BK10, BK11〜BK13 | 完了画面・削除画面・レビュー画面はお勧めフラグを扱わないため影響なし |
