# 設計書修正レポート：書籍一覧「出版社による検索」追加

## 1. 対象要件

```
・書籍の検索機能に「出版社による検索」を追加する
・出版社はプルダウンで選択可能にする
・ただし出版社は DB でマスター管理するものではなく、既に登録されている書籍データより
　重複を排除してプルダウンに表示するものでよい
```

## 4. 詳細な修正内容（Before / After）

### 4.1 [05個別画面設計_BK01_書籍一覧画面.md](../../../Docsシステム/外部設計/05個別画面設計/05個別画面設計_BK01_書籍一覧画面.md)

#### (1) 2.1 検索条件エリア — 項目表に「出版社」を追加

**目的:** 出版社プルダウンによる検索条件を新設するため。

```diff
 | タイトル | searchTitle | text | - | 100 | - | 部分一致検索 |
 | 著者名 | searchAuthor | text | - | 50 | - | 部分一致検索 |
 | カテゴリ | searchCategory | select | - | - | 全て | プルダウン選択 |
+| 出版社 | searchPublisher | select | - | - | 全て | プルダウン選択。完全一致検索 |
 | 検索ボタン | btnSearch | button | - | - | - | - |
 | クリアボタン | btnClear | button | - | - | - | 検索条件をクリア |
```

- カテゴリ選択肢の説明の直後に、出版社選択肢の説明を追加

```diff
 **選択肢の取得元:** categoriesテーブルから全件取得（category_idの昇順）

+**出版社選択肢:**
+- 全て（値: ""）
+- 書籍テーブルに登録済みの出版社（値: 出版社名そのもの）
+
+**選択肢の取得元:** 出版社を管理するマスターテーブルは持たず、書籍テーブルの出版社列から重複を排除して取得する（五十音順）
```

#### (2) 3.1 初期表示処理 — 出版社選択肢の取得処理を追加

**目的:** 画面初期表示時に出版社プルダウンへ選択肢（重複排除済み）を設定するため。

```diff
 1. 書籍テーブルから全書籍データを取得し、レビューテーブルと外部結合して平均評価・レビュー数を集計する
 2. categoriesテーブルからカテゴリ選択肢を全件取得し、プルダウンに設定する
-3. デフォルトソート条件: 書籍ID 降順で並び替え
-4. ページング処理を行い、1ページあたり20件を表示
-5. 取得した書籍一覧データをビューに渡して表示
+3. 書籍テーブルから出版社を重複排除して取得し、プルダウンに設定する
+4. デフォルトソート条件: 書籍ID 降順で並び替え
+5. ページング処理を行い、1ページあたり20件を表示
+6. 取得した書籍一覧データをビューに渡して表示
```

- 出版社選択肢取得のSQLをカテゴリ選択肢取得SQLの直後に追加

```diff
 -- カテゴリ選択肢取得
 SELECT category_id, category_name
 FROM カテゴリテーブル
 ORDER BY category_id

+-- 出版社選択肢取得（重複排除、マスターテーブルなし）
+SELECT DISTINCT 書籍テーブル.出版社
+FROM 書籍テーブル
+ORDER BY 書籍テーブル.出版社
+
 SELECT
     書籍テーブル.書籍ID,
     ...
```

- OUTPUT表に「出版社選択肢」を追加

```diff
 | 書籍一覧 | DTO | 書籍ID, タイトル, 著者, カテゴリ名, 出版日, お勧めフラグ, 平均評価, レビュー数 |
 | カテゴリ選択肢 | DTO | 全カテゴリID・名称のリスト |
+| 出版社選択肢 | DTO | 書籍テーブルから重複排除した出版社名のリスト |
 | ページ情報 | DTO | 総件数、現在ページ、総ページ数 |
```

#### (3) 3.2 検索ボタン押下時 — 出版社を検索条件として追加

**目的:** ユーザーが出版社を選択して検索できるようにするため。

- INPUT表に「出版社」を追加

```diff
 | タイトル | リクエスト | 任意。部分一致 |
 | 著者名 | リクエスト | 任意。部分一致 |
 | カテゴリ | リクエスト | 任意。「全て」選択時は条件なし |
+| 出版社 | リクエスト | 任意。「全て」選択時は条件なし。完全一致 |
```

- 処理内容の説明を修正（カテゴリ・出版社は完全一致であることを明記）

```diff
-1. 入力された検索条件でタイトル・著者名は部分一致、カテゴリは完全一致で書籍テーブルを検索する
+1. 入力された検索条件でタイトル・著者名は部分一致、カテゴリ・出版社は完全一致で書籍テーブルを検索する
```

- 検索SQLの WHERE 句に出版社条件を追加

```diff
 WHERE 書籍テーブル.タイトル LIKE :タイトル        -- 入力がある場合のみ
   AND 書籍テーブル.著者 LIKE :著者名              -- 入力がある場合のみ
   AND 書籍テーブル.カテゴリ = :カテゴリ            -- 「全て」以外が選択された場合のみ
+  AND 書籍テーブル.出版社 = :出版社                -- 「全て」以外が選択された場合のみ
```

- OUTPUT表に「出版社選択肢」「検索条件（出版社）→セッション」を追加

```diff
 | 書籍一覧 | DTO | 検索条件に合致した書籍一覧（お勧めフラグ含む） |
 | カテゴリ選択肢 | DTO | 全カテゴリID・名称のリスト |
+| 出版社選択肢 | DTO | 書籍テーブルから重複排除した出版社名のリスト |
 | ページ情報 | DTO | 総件数、現在ページ、総ページ数 |
 | 検索条件（タイトル） | セッション | - |
 | 検索条件（著者名） | セッション | - |
 | 検索条件（カテゴリID） | セッション | - |
+| 検索条件（出版社） | セッション | - |
```

#### (4) 3.3 クリアボタン押下時 / 3.4 ソートリンク押下時 / 3.9 ページネーション押下時 — 文言を明確化

**目的:** 既存の「検索条件を維持・削除」という記述の対象に、出版社検索条件が含まれることを明記するため（処理ロジック自体の変更はなし）。

```diff
 # 3.3 クリアボタン押下時
-2. セッションに保存されている検索条件を削除
+2. セッションに保存されている検索条件（タイトル・著者名・カテゴリ・出版社）を削除
```

```diff
 # 3.4 ソートリンク押下時
-2. 現在の検索条件を維持したまま、3.1または3.2と同じSQLに `ORDER BY :ソート列 :ソート順` を適用して再取得する
+2. 現在の検索条件（タイトル・著者名・カテゴリ・出版社）を維持したまま、3.1または3.2と同じSQLに `ORDER BY :ソート列 :ソート順` を適用して再取得する
```

```diff
 # 3.9 ページネーション押下時
-2. 現在の検索条件・ソート条件を維持
+2. 現在の検索条件（タイトル・著者名・カテゴリ・出版社）・ソート条件を維持
```

- 影響調査レポート（[work/機能追加・改善/テーマ３/影響調査レポート.md](./影響調査レポート.md)）で「○」と判定した
