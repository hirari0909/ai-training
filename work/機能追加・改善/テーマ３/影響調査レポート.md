# 影響調査レポート：書籍一覧「出版社による検索」追加

## 1. 対象要件

```
・書籍の検索機能に「出版社による検索」を追加する
・出版社はプルダウンで選択可能にする
・ただし出版社は DB でマスター管理するものではなく、既に登録されている書籍データより
　重複を排除してプルダウンに表示するものでよい
```

## 2. 調査方針

- 調査範囲: `Docsシステム/外部設計` 配下の設計書のみ
- 本レポートは**影響調査のみ**であり、設計書本体・画面イメージ（HTML/img）はまだ修正していない
- 「出版社」は既存の `books.publisher` カラム（VARCHAR(50) NOT NULL）をそのまま検索条件として利用する前提。
  カテゴリのようなマスターテーブル（`categories`）は新設せず、`books` テーブルの `publisher` 列を
  `DISTINCT` 集計してプルダウンの選択肢とする方式で影響範囲を洗い出した
- DBスキーマ（テーブル・カラム自体）に変更はないため、`03ER図.md`・`04TBL定義.md` は対象外と判断（詳細は3節参照）

## 4. 詳細な修正内容案

### 4.1 [05個別画面設計_BK01_書籍一覧画面.md](../../../Docsシステム/外部設計/05個別画面設計/05個別画面設計_BK01_書籍一覧画面.md)

#### (1) 2.1 検索条件エリア の項目表に追加

| 項目名 | 項目ID | 型 | 必須 | 最大長 | 初期値 | 備考 |
|--------|--------|-----|------|--------|--------|------|
| 出版社 | searchPublisher | select | - | - | 全て | プルダウン選択 |

- **選択肢の取得元:** カテゴリのようなマスターテーブルは持たず、`books` テーブルの `publisher` 列から
  重複を排除して取得する（`SELECT DISTINCT publisher FROM books ORDER BY publisher`）
- 選択肢は「全て」（値: 空文字）＋ 実データから取得した出版社名の一覧（アルファベット/五十音順）
- 既存の「カテゴリ」欄と同様に部分一致ではなく完全一致検索とする（プルダウン選択のため）

#### (2) 3.1 初期表示処理 の修正

- INPUTなし（既存通り）
- 処理内容に「出版社選択肢の取得」を追加

```diff
 1. 書籍テーブルから全書籍データを取得し、レビューテーブルと外部結合して平均評価・レビュー数を集計する
 2. categoriesテーブルからカテゴリ選択肢を全件取得し、プルダウンに設定する
+3. 書籍テーブルから出版社を重複排除して取得し、プルダウンに設定する
 4. デフォルトソート条件: 書籍ID 降順で並び替え
 5. ページング処理を行い、1ページあたり20件を表示
 6. 取得した書籍一覧データをビューに渡して表示
```

- 出版社選択肢取得のSQLを追加

```sql
-- 出版社選択肢取得（重複排除、マスターテーブルなし）
SELECT DISTINCT 書籍テーブル.出版社
FROM 書籍テーブル
ORDER BY 書籍テーブル.出版社
```

- OUTPUT表に「出版社選択肢」を追加（DTO: 出版社名のリスト）

#### (3) 3.2 検索ボタン押下時 の修正

- INPUT表に「出版社」を追加（リクエスト、任意。「全て」選択時は条件なし、完全一致）
- 検索SQLの WHERE 句に出版社条件を追加

```diff
 WHERE 書籍テーブル.タイトル LIKE :タイトル        -- 入力がある場合のみ
   AND 書籍テーブル.著者 LIKE :著者名              -- 入力がある場合のみ
   AND 書籍テーブル.カテゴリ = :カテゴリ            -- 「全て」以外が選択された場合のみ
+  AND 書籍テーブル.出版社 = :出版社                -- 「全て」以外が選択された場合のみ
```

- OUTPUT表に「出版社選択肢」「検索条件（出版社）→セッション」を追加

#### (4) 3.3 クリアボタン押下時

- 「セッションに保存されている検索条件を削除」の対象に出版社検索条件を含める旨を明記（他の検索条件と同様の扱いのため実質的な処理変更はなし）

#### (5) 3.4 ソートリンク押下時 / 3.9 ページネーション押下時

- 「現在の検索条件を維持したまま」の対象に出版社検索条件を含める旨を明記（処理自体は既存条件維持ロジックの延長のため大きな変更はなし）

#### (6) 画面イメージ差し替え

- HTML: [BK01.html](../../../Docsシステム/外部設計/05個別画面設計/html/BK01.html)
  - 検索条件エリア（`search-section` 内の `<div class="row g-3">`）に「出版社」プルダウンを追加
  - 現状は タイトル／著者名／カテゴリ の3項目を `col-md-4` で1行に配置しているため、
    出版社を追加する場合は4項目を `col-md-3` に変更して1行に収める案、
    または2行目に折り返す案のいずれかで再配置する（実装時に確定）
  - `<select id="searchPublisher" name="searchPublisher">` として、モックでは実データ例
    （リーダブルコードの出版社など）からいくつかサンプルの `<option>` を用意する
- img: [BK01.png](../../../Docsシステム/外部設計/05個別画面設計/img/BK01.png)
  - HTML変更後、画面キャプチャ（`tools/screenCapture`）で再作成し差し替え

## 7. 補足（設計書のスコープ外・参考情報）

以下は `Docsシステム/外部設計` の範囲外だが、後続のCD（コーディング）フェーズで影響が想定される実装箇所の参考情報。

- `Docsシステム/詳細設計/モジュール一覧.md`: `BookMapper`/`BookService` に出版社一覧取得メソッド
  （例: `findAllPublishers`）の追加、および `BookListController.list` の処理概要に出版社検索対応を追記する必要がある
- `training-bookshelf` 実装側: `BookMapper.xml`（`findAll`/`count`）への出版社条件追加、
  `BookListController`/`BookService` への `searchPublisher` パラメータ追加、
  `BookConstants` へのセッションキー（例: `SESSION_SEARCH_PUBLISHER`）追加、
  `BK01_BookList.html`（Thymeleafテンプレート）への出版社プルダウン追加が必要
- これらはCD・UTフェーズの対象であり、本レポート（外部設計の影響調査）のスコープ外のため詳細検討は次フェーズで実施する

## 8. まとめ

- 出版社は既存カラムを流用し、マスターテーブルを新設しない方針のため、DB設計書（ER図・テーブル定義）の修正は**不要**。
- 修正が必要なのは書籍一覧画面（BK01）の設計書1件のみ。検索条件エリアへの項目追加、初期表示・検索処理のSQL・INPUT/OUTPUT追加が必要。
- 画面イメージ（HTML/img）もBK01のみ差し替えが必要。
- 本レポートは影響調査のみであり、設計書・画面イメージの実修正は未実施。
