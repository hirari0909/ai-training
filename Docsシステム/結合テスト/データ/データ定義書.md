- 期待結果（URL の `/book/detail/{bookId}` 等）と一致させるため、`book_id` / `review_id` を明示固定

## 6. 制約セルフチェック（投入前確認済み）
- `books.isbn`：全50件 UNIQUE・13桁数字（重複なし）
- `books.price >= 0`：全件 0以上（CHECK充足）
- `books.category_id`：全件 1〜9（categories に存在・FK充足）
- NOT NULL カラム（title/author/publisher/published_date/isbn/category_id/price）：全件設定
- `reviews.rating`：全件 1〜5（CHECK充足）
- `reviews.book_id`：実在 book_id を参照（FK充足）
- INSERT順序：categories → books → reviews（FK依存順）
- `created_at`/`updated_at`（books）：DEFAULT に委譲。`reviews.created_at` は表示順検証のため明示

## 7. 再実施時の運用
- データを変更する操作（登録/更新/削除）後に前提が崩れる場合は**アプリ再起動で初期化**してから次ケースへ（H2インメモリのため冪等）
- ケース側（01）の事前準備・期待結果と本データに齟齬が出た場合は、本書とケースを同期して解消する
