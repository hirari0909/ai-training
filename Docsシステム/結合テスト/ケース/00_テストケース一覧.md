## 4. 整合性メモ
- 総ケース数 43 ＝ 各シナリオ詳細ファイルのケース数合計（8+9+5+5+7+9）
- ケースNoは `{シナリオID}-{連番3桁}`。重複・欠番なし
- データ前提（既知 book_id・ISBN・件数41以上 等）は「02.データ作成」の data.sql と同期すること。乖離があれば本一覧と詳細を更新
- メッセージID表記の設計書間乖離（BK11 の `validation.maxlength`/`validation.range` ↔ 06メッセージ一覧 の `validation.length.max`/`validation.number.range`）は SC05 備考に記載済み。実施時に実装値を確認し結果報告へ集約
