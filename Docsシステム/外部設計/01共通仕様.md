# 01. 共通仕様
## training-bookshelf

---

## 1. システム概要

本システムは、書籍情報の登録・閲覧・編集・削除を行う管理システムです。
また、各書籍に対してレビューを投稿・閲覧する機能を提供します。

### 対象ユーザー
- 社内研修用教材として使用
- Spring Boot/Java の学習者を想定

### 使用技術
- バックエンド: Spring Boot 3.x (Java 21)
- テンプレートエンジン: Thymeleaf
- データベース: MySQL 8.x
- フロントエンド: HTML5, CSS3, JavaScript

---

## 2. エラーハンドリング

### 2.1 バリデーションエラー
- エラーメッセージを入力画面に赤字で表示
- 入力値は保持
- エラー項目にフォーカス

**エラーメッセージ例:**
- 「タイトルは必須です」
- 「タイトルは100文字以内で入力してください」
- 「出版日は正しい日付形式で入力してください」
- 「ISBNは10桁または13桁の数字で入力してください」
- 「価格は0以上の整数で入力してください」

### 2.2 データベースエラー
- システムエラー画面を表示
- エラーログに記録（ログファイル: logs/application.log）
- ロールバック処理
- ユーザーには「システムエラーが発生しました。管理者にお問い合わせください。」と表示

### 2.3 データ不整合エラー
- 該当データが存在しない場合
  - エラーメッセージを表示: 「指定された書籍が見つかりません」
  - 一覧画面へ自動遷移（3秒後）

### 2.4 同時更新制御
- updated_at を使った楽観的ロック
- 更新時に updated_at が変更されている場合はエラー
- エラーメッセージ: 「他のユーザーによって更新されています。最新のデータを取得してください。」

## 3. セキュリティ要件

### 3.1 SQLインジェクション対策
- JPA/Hibernate を使用したパラメータバインディング
- PreparedStatement による SQL 実行
- 動的にSQL文を組み立てない

**実装例:**
```java
@Query("SELECT b FROM Book b WHERE b.bookId = :bookId")
Optional<Book> findById(@Param("bookId") Long bookId);
```

### 3.2 XSS対策
- Thymeleaf のデフォルトエスケープ機能を使用
- `th:text` で自動的にHTMLエスケープ
- ユーザー入力値は必ずエスケープして表示

**実装例:**
```html
<p th:text="${book.title}"></p>  <!-- 自動エスケープ -->
```

### 3.3 CSRF対策
- Spring Security の CSRF 保護機能を使用
- 全てのフォームに CSRF トークンを自動付与
- POST/PUT/DELETE リクエスト時にトークンを検証

**実装例:**
```html
<form th:action="@{/book/register}" method="post">
    <!-- CSRF トークンは Spring Security が自動付与 -->
    <input type="hidden" th:name="${_csrf.parameterName}" th:value="${_csrf.token}"/>
</form>
```

### 3.4 セッション管理
- セッションIDの定期的な再生成
- セッションタイムアウトの設定: 30分
- セッションIDをURLに含めない
- Cookieに HttpOnly と Secure フラグを設定

**実装例（application.properties）:**
```properties
server.servlet.session.timeout=30m
server.servlet.session.cookie.http-only=true
server.servlet.session.cookie.secure=true
server.servlet.session.cookie.same-site=strict
```

### 3.5 パスワード管理（将来拡張時）
- BCryptPasswordEncoder を使用
- bcrypt アルゴリズム
- ソルトは自動生成

## 5. 画面共通仕様

### 5.1 ヘッダー
- 全画面共通
- アプリケーション名: 「書籍管理システム」
- ナビゲーション
  - 書籍一覧へのリンク

### 5.2 フッター
- 全画面共通
- コピーライト表示: 「© 2024 Training BookShelf」

### 5.3 ページネーション
- 1ページあたりの表示件数: 20件
- 表示形式: « 前へ | 1 2 3 4 5 | 次へ »
- 現在のページ番号をハイライト表示
- Spring Data JPA の Pageable を使用

### 5.4 日時表示形式

| 種類 | 形式 | 例 |
|------|------|-----|
| 日付 | YYYY-MM-DD | 2024-12-15 |
| 日時 | YYYY-MM-DD HH:MM | 2024-12-15 14:30 |
| 日時（秒付き） | YYYY-MM-DD HH:MM:SS | 2024-12-15 14:30:45 |

### 5.5 通貨表示
- 形式: 数値 + 円
- 例: 1,500円
- カンマ区切りで表示

### 5.6 評価表示
- 星5段階評価
- 表示: ★★★★☆
- 平均評価は小数点1桁まで表示（例: 4.3）

## 6. データベース共通仕様

### 6.1 命名規則
- テーブル名: 小文字、複数形（例: books, reviews）
- カラム名: スネークケース（例: book_id, created_at）
- 主キー: テーブル名の単数形 + _id（例: book_id）
- 外部キー: 参照先テーブルの主キー名（例: book_id）

### 6.2 共通カラム
以下のカラムは全テーブルに含める:

| カラム名 | 型 | 説明 |
|---------|-----|------|
| created_at | DATETIME | 作成日時（デフォルト: CURRENT_TIMESTAMP） |
| updated_at | DATETIME | 更新日時（デフォルト: CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP） |

### 6.3 文字コード・照合順序
- 文字セット: utf8mb4
- 照合順序: utf8mb4_unicode_ci

### 6.4 ストレージエンジン
- InnoDB を使用
- 外部キー制約をサポート
- トランザクション処理をサポート

## 8. コーディング規約

### 8.1 Java
- Google Java Style Guide に準拠
- インデント: スペース2つ
- 改行コード: LF
- ファイルエンコーディング: UTF-8（BOMなし）

### 8.2 命名規則
- クラス名: パスカルケース（例: BookController）
- メソッド名: キャメルケース（例: getBookList）
- 変数名: キャメルケース（例: bookId）
- 定数名: 大文字スネークケース（例: MAX_DISPLAY_COUNT）
- パッケージ名: 小文字のみ（例: com.example.bookshelf.controller）

### 8.3 コメント
- クラスとメソッドに Javadoc コメントを記載
- 複雑なロジックには行コメントを追加
- TODOコメントには担当者と日付を記載

**例:**
```java
/**
 * 書籍情報を管理するコントローラー
 */
@Controller
@RequestMapping("/book")
public class BookController {
    /**
     * 書籍一覧を表示
     * @param model モデル
     * @return 書籍一覧画面
     */
    @GetMapping("/list")
    public String list(Model model) {
        // 処理
    }
}
```
