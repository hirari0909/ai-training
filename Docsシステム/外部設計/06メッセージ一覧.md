# 05. メッセージ一覧
## training-bookshelf

---

## 1. 概要

本ドキュメントは、書籍管理システムで使用する全てのメッセージを定義します。  
メッセージIDと本文で構成し、そのままプログラムリソース（messages.properties）として利用可能な形式で記載します。

**置換パラメータの表記:**
- `{0}`, `{1}`, `{2}` ... : MessageFormat形式の置換パラメータ
- 例: `{0}は必須です` → "タイトルは必須です"


```properties

validation.number.max={0}は{1}以下で入力してください
validation.number.range={0}は{1}以上{2}以下で入力してください
```

```properties

validation.isbn.format=ISBNは10桁または13桁の数字で入力してください
validation.isbn.checkdigit=ISBNのチェックデジットが正しくありません
```

```properties

```

## 7. 使用例

### 7.1 Javaコードでの使用例

```java
// MessageSourceを使用した例
@Autowired
private MessageSource messageSource;

// 必須チェックエラー
String errorMessage = messageSource.getMessage(
    "validation.required", 
    new Object[]{"タイトル"}, 
    Locale.JAPANESE
);
// 結果: "タイトルは必須です"

// 文字数チェックエラー
String errorMessage = messageSource.getMessage(
    "validation.length.max", 
    new Object[]{"タイトル", "100"}, 
    Locale.JAPANESE
);
// 結果: "タイトルは100文字以内で入力してください"

// 登録完了メッセージ
String successMessage = messageSource.getMessage(
    "success.register", 
    new Object[]{"書籍"}, 
    Locale.JAPANESE
);
// 結果: "書籍の登録が完了しました"
```

### 7.2 Thymeleafでの使用例

```html
<!-- メッセージキーを直接指定 -->
<h1 th:text="#{bk01.title}">書籍一覧</h1>

<!-- パラメータ付きメッセージ -->
<p th:text="#{validation.required('タイトル')}">タイトルは必須です</p>

<!-- エラーメッセージの表示 -->
<span th:if="${#fields.hasErrors('title')}" 
      th:errors="*{title}" 
      class="error">
</span>
```
