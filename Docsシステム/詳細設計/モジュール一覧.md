## モジュール一覧

### HTML

| 書籍編集入力画面 | BK06_BookEditInput.html | 書籍編集の入力フォームを表示する |
| 書籍編集確認画面 | BK07_BookEditConfirm.html | 編集内容の確認を表示する |
| 書籍編集完了画面 | BK08_BookEditComplete.html | 編集完了のメッセージを表示する |
| 書籍削除確認画面 | BK09_BookDeleteConfirm.html | 削除対象の確認を表示する |
| 書籍削除完了画面 | BK10_BookDeleteComplete.html | 削除完了のメッセージを表示する |

| レビュー投稿確認画面 | BK12_ReviewPostConfirm.html | 投稿内容の確認を表示する |
| レビュー投稿完了画面 | BK13_ReviewPostComplete.html | 投稿完了のメッセージを表示する |

### Controller

| モジュール論理名 | モジュール名 | メソッド名 | 処理概要 |
|----------------|-------------|-----------|---------|
| 書籍一覧表示 | BookListController | list | 書籍一覧を取得してBK01を返す |
| 検索条件クリア | BookListController | clearSearch | 検索条件をクリアして一覧にリダイレクトする |
| 書籍詳細表示 | BookDetailController | detail | 指定IDの書籍を取得してBK02を返す |
| 書籍登録フォーム表示 | BookRegisterController | newForm | 空の登録フォーム（BK03）を返す |
| 書籍登録確認表示 | BookRegisterController | confirmRegister | 入力内容をバリデーションしてBK04を返す |
| 書籍登録処理 | BookRegisterController | register | 書籍を登録してBK05にリダイレクトする |
| 書籍登録キャンセル | BookRegisterController | cancelRegister | セッションを削除して一覧にリダイレクトする |
| 書籍編集フォーム表示 | BookEditController | editForm | 指定IDの書籍情報を取得してBK06を返す |
| 書籍編集確認表示 | BookEditController | confirmEdit | 編集内容をバリデーションしてBK07を返す |
| 書籍更新処理 | BookEditController | update | 書籍情報を更新してBK08にリダイレクトする |
| 書籍編集キャンセル | BookEditController | cancelEdit | セッションを削除して詳細にリダイレクトする |
| 書籍削除確認表示 | BookDeleteController | confirmDelete | 指定IDの書籍を取得してBK09を返す |
| 書籍削除処理 | BookDeleteController | delete | 書籍を削除してBK10にリダイレクトする |
| レビュー投稿フォーム表示 | ReviewController | newForm | 書籍情報を取得してBK11を返す |
| レビュー投稿確認表示 | ReviewController | confirmReview | 入力内容をバリデーションしてBK12を返す |
| レビュー投稿処理 | ReviewController | postReview | レビューを登録してBK13にリダイレクトする |

### Service

| モジュール論理名 | モジュール名 | メソッド名 | 処理概要 |
|----------------|-------------|-----------|---------|
| 書籍全件取得 | BookService | findAll | すべての書籍を取得して返す |
| 書籍1件取得 | BookService | findById | 指定IDの書籍を取得して返す |
| 書籍登録 | BookService | register | 書籍情報をDBに登録する（category_idを使用） |
| 書籍更新 | BookService | update | 指定IDの書籍情報をDBで更新する（category_idを使用） |
| 書籍削除 | BookService | delete | 指定IDの書籍をDBから削除する |
| カテゴリ一覧取得 | CategoryService | findAll | categoriesテーブルから全件取得して返す（プルダウン用） |
| レビュー登録 | ReviewService | register | レビュー情報をDBに登録する |

### Mapper

| モジュール論理名 | モジュール名 | メソッド名 | 処理概要 |
|----------------|-------------|-----------|---------|
| カテゴリ全件取得 | CategoryMapper | findAll | categoriesテーブルから全レコードを取得する |
| 書籍全件取得 | BookMapper | findAll | booksテーブルから全レコードを取得する（categoriesテーブルとJOIN） |
| 書籍1件取得 | BookMapper | findById | booksテーブルから指定IDのレコードを取得する（categoriesテーブルとJOIN） |
| 書籍登録 | BookMapper | insert | booksテーブルにレコードを挿入する |
| 書籍更新 | BookMapper | update | booksテーブルの指定IDのレコードを更新する |
| 書籍削除 | BookMapper | delete | booksテーブルの指定IDのレコードを削除する |
| レビュー登録 | ReviewMapper | insert | reviewsテーブルにレコードを挿入する |
| レビュー一覧取得 | ReviewMapper | findByBookId | reviewsテーブルから指定書籍IDのレコードを全件取得する |

| モジュール論理名 | モジュール名 | 処理概要 |

### パッケージについて
ベースパッケージは下記とする事
jp.co.s.training.bookshelf

### メソッド名のルールについて
1. lowerCamelCase を使用する
2. 動詞から始める
3. 処理内容が分かる具体的な名前にする
4. boolean を返すメソッドは状態・判定が分かる名前にする(isXXX)
