## ネーミングルール

### 共通規則

| 種別 | 形式 | 例 |
|------|------|----|
| クラス名・インターフェース名 | UpperCamelCase | `BookController` |
| メソッド名・変数名・フィールド名 | lowerCamelCase | `findAll`, `bookId` |
| 定数 | UPPER_SNAKE_CASE | `MAX_PAGE_SIZE` |
| パッケージ名 | すべて小文字 | `controller`, `service` |
| DBカラム名・テーブル名 | snake_case | `book_id`, `published_date` |

---

### Controllerクラス名

作成単位：機能（ドメイン）単位  
ルール：`{機能名}Controller`  
例：`BookController`

#### URL

ルール：`/{機能名（複数形）}/{アクション}` — すべて小文字・ケバブケース  
例：`GET /books`、`GET /books/{bookId}`、`GET /books/new`

#### Controllerメソッド名

ルール：操作内容を表すlowerCamelCase  
例：`list`、`detail`、`newForm`、`register`、`editForm`、`update`、`confirmDelete`、`delete`

---

### サービスクラス名

作成単位：機能（ドメイン）単位  
ルール：`{機能名}Service`  
例：`BookService`

#### サービスメソッド名

ルール：操作内容を表すlowerCamelCase  
例：`findAll`、`findById`、`register`、`update`、`delete`

---

### MyBatisのMapperクラス名

作成単位：テーブル単位（主要な軸になるTBL）  
ルール：`{テーブル名（単数形PascalCase）}Mapper`  
例：`BookMapper`

#### Mapperメソッド名

ルール：SQL操作を表すlowerCamelCase  
例：`findAll`、`findById`、`insert`、`update`、`delete`

---

### Entityクラス名

作成単位：テーブル単位  
ルール：`{テーブル名（単数形PascalCase）}`（サフィックスなし）  
例：`Book`

- `@Data`（Lombok）を使用してgetter/setter/toString等を自動生成
- フィールド名はlowerCamelCase（MyBatisの`map-underscore-to-camel-case=true`に対応）

---

### Thymeleafのテンプレートファイル名

ルール：`templates/{機能名}/{画面ID}_{画面名英語表記}.html`  
例：`templates/book/BK01_BookList.html`

---

### フォームクラス名（入力値受け取り用）

ルール：`{機能名}{操作名}Form`  
例：`BookRegisterForm`、`BookEditForm`

---

### messages.propertiesのキー名

ルール：`{画面ID（小文字）}.{種別}.{内容}` / 共通は `common.{種別}.{内容}`  
例：`bk01.message.nodata`、`validation.required`、`common.system.error`

---

### テストクラス名

ルール：`{テスト対象クラス名}Test`  
例：`BookControllerTest`、`BookServiceTest`、`BookMapperTest`


---

### Controllerクラス名

作成単位：機能（ドメイン）単位  
ルール：`{機能名}Controller`

| 機能 | クラス名 |
|------|----------|
| 書籍管理 | `BookController` |

#### URL

ルール：`/{機能名（複数形）}/{アクション}` — RESTfulスタイル、すべて小文字・ケバブケース

| 画面 | HTTPメソッド | URL | 説明 |
|------|-------------|-----|------|
| BK01 書籍一覧 | GET | `/books` | 一覧表示 |
| BK02 書籍詳細 | GET | `/books/{bookId}` | 詳細表示 |
| BK03 書籍登録入力 | GET | `/books/new` | 登録フォーム表示 |
| BK04 書籍登録確認 | POST | `/books/confirm` | 登録内容確認 |
| BK05 書籍登録完了 | POST | `/books` | 登録処理・完了画面 |
| BK06 書籍編集入力 | GET | `/books/{bookId}/edit` | 編集フォーム表示 |
| BK07 書籍編集確認 | POST | `/books/{bookId}/confirm` | 編集内容確認 |
| BK08 書籍編集完了 | PUT / POST | `/books/{bookId}` | 更新処理・完了画面 |
| BK09 書籍削除確認 | GET | `/books/{bookId}/delete` | 削除確認画面 |
| BK10 書籍削除完了 | DELETE / POST | `/books/{bookId}` | 削除処理・完了画面 |

#### Controllerメソッド名

| 操作 | メソッド名 |
|------|-----------|
| 一覧表示 | `list` |
| 詳細表示 | `detail` |
| 登録フォーム表示 | `newForm` |
| 登録確認表示 | `confirmRegister` |
| 登録処理 | `register` |
| 編集フォーム表示 | `editForm` |
| 編集確認表示 | `confirmEdit` |
| 更新処理 | `update` |
| 削除確認表示 | `confirmDelete` |
| 削除処理 | `delete` |

---

### サービスクラス名

作成単位：機能（ドメイン）単位  
ルール：`{機能名}Service`

| 機能 | クラス名 |
|------|----------|
| 書籍管理 | `BookService` |

#### サービスメソッド名

| 操作 | メソッド名 | 戻り値の例 |
|------|-----------|-----------|
| 全件取得 | `findAll` | `List<Book>` |
| 1件取得 | `findById` | `Book` |
| 登録 | `register` | `void` |
| 更新 | `update` | `void` |
| 削除 | `delete` | `void` |
| 存在確認 | `existsById` | `boolean` |
| 重複チェック | `isDuplicateIsbn` | `boolean` |

---

### MyBatisのMapperクラス名

作成単位：テーブル単位（主要な軸になるTBL）  
ルール：`{テーブル名（単数形PascalCase）}Mapper`

| テーブル | クラス名 |
|---------|----------|
| books | `BookMapper` |

#### Mapperメソッド名

| 操作 | メソッド名 | SQL種別 |
|------|-----------|--------|
| 全件取得 | `findAll` | SELECT |
| 1件取得 | `findById` | SELECT |
| 登録 | `insert` | INSERT |
| 更新 | `update` | UPDATE |
| 削除 | `delete` | DELETE |
| 件数取得 | `count` | SELECT |
| 重複確認 | `findByIsbn` | SELECT |

---

### Entityクラス名

作成単位：テーブル単位  
ルール：`{テーブル名（単数形PascalCase）}`（サフィックスなし）

| テーブル | クラス名 |
|---------|----------|
| books | `Book` |

- `@Data`（Lombok）を使用してgetter/setter/toString等を自動生成
- フィールド名はlowerCamelCase（MyBatisの`map-underscore-to-camel-case=true`に対応）

---

### Thymeleafのテンプレートファイル名

ルール：`{ディレクトリ}/{画面ID}_{画面名英語表記}.html`  
ディレクトリはControllerのRequestMappingのパスに対応させる

| 画面ID | ファイルパス |
|--------|-------------|
| BK01 書籍一覧 | `templates/book/BK01_BookList.html` |
| BK02 書籍詳細 | `templates/book/BK02_BookDetail.html` |
...

---

### フォームクラス名（入力値受け取り用）

ルール：`{機能名}{操作名}Form`

| 用途 | クラス名 |
|------|----------|
| 書籍登録フォーム | `BookRegisterForm` |
| 書籍編集フォーム | `BookEditForm` |

---

### messages.propertiesのキー名

ルール：`{画面ID（小文字）}.{種別}.{内容}`  
共通メッセージは `common.{種別}.{内容}`

| キー例 | 内容 |
|--------|------|
| `bk01.message.nodata` | 一覧データなし |
| `bk04.message.confirm` | 登録確認メッセージ |
| `bk05.message.success` | 登録完了メッセージ |
| `validation.required` | 必須チェックエラー |
| `validation.isbn.format` | ISBNフォーマットエラー |
| `common.system.error` | システムエラー |

---

### テストクラス名

ルール：`{テスト対象クラス名}Test`

| 対象 | テストクラス名 |
|------|--------------|
| `BookController` | `BookControllerTest` |
| `BookService` | `BookServiceTest` |
| `BookMapper` | `BookMapperTest` |
